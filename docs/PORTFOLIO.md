# Portfolio description

**Secure Entry — liveness and identity verification kiosk**

Contributed to a team-built Python/FastAPI kiosk integrating a MiniFASNet ensemble,
MediaPipe action challenges and AWS Rekognition 1:1 identity verification. Developed
evaluation tooling and demo interfaces, integrated enrollment and access policies,
and added deadline tests preventing late results from becoming approvals.

Discuss concurrent identity work, missing-signal handling, separate first-pass and
step-up timing, protected enrollment, durable offline events and the failed passive
gate. Do not claim sole authorship, production deployment, accuracy improvements or
guaranteed sub-two-second authentication without corresponding measured evidence.
